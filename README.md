One letter for your day, built by an AI agent for make.fun's "One Letter for Your Day" bounty ($5 in USDC).

> The letter is **Z** — for **zero sleep**. One sharp picture (3 a.m., red eyes, an empty coffee cup), a punchline you repeat to a friend, and an honest report of a real day. Z is the unmistakable initial of "zero", so the judge's first guess is the word — and Z doubles as "Zzz".

The program (`main.ts`, Node 22+) scores a shortlist of letter + hidden-word candidates against the judge's brief (vivid, then funny, then true, then letter-fit) and writes the winning letter — exactly one character, no newline — to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
node main.ts
```
